# Total Variation Denoising

This project removes Gaussian noise from greyscale images using isotropic total variation (TV). It reproduces Chambolle's fixed-point denoising method and compares it with a noise-adaptive version.

The baseline uses a fixed TV weight, $\lambda=0.20$. The modified method estimates the noise standard deviation, $\hat{\sigma}$, from the noisy image and sets $\lambda=\max(\alpha\hat{\sigma},10^{-8})$. Validation data selected $\alpha=1.0$. The modification changes the TV weight; both methods use the same denoising algorithm, input images, step size and number of iterations.

The project is based on A. Chambolle, “An Algorithm for Total Variation Minimization and Applications,” *Journal of Mathematical Imaging and Vision*, 20, 89–97, 2004 ([DOI](https://doi.org/10.1023/B:JMIV.0000011325.36760.1e)). The discrete operators and synthetic image task follow the EEP55C36 course handout, “Final-project mathematical guide: Image processing: total-variation denoising,” Trinity College Dublin, 2026. No external image dataset or third-party denoising solver is used; the images are generated by this project.

## Repository files

- `src/baseline.py` contains the fixed-weight Chambolle denoiser
- `src/modified.py` contains the adaptive denoiser
- `src/data.py` creates the synthetic images and estimates noise
- `src/metrics.py` calculates MSE and PSNR
- `run_experiments.py` tunes parameters and runs paired comparisons
- `run_texture_stress.py` runs the checkerboard stress case
- `plot_results.py` makes the overall comparison and normal-image example
- `tests/test_denoising.py` contains six local checks
- `.vscode/launch.json` provides a VS Code launch option for the baseline demo
- `outputs/` stores selected parameters, result tables and figures
- `report/` stores the report source, PDF and PDF build script

The assignment shows `configs/smoke.json` and `configs/final.json` as an example layout. This project uses command-line settings for each run and saves the validation-selected values in `outputs/selected_parameters.json`. That file is used for the full test run and stress case. The smoke command and full command below record the other settings.

## Tested environment and setup

The project was run on a MacBook Pro with an Apple M1 Pro chip and macOS 27.2.1, using Python 3.12.16, NumPy 2.5.4 and Matplotlib 3.11.2. These Python package versions are pinned in `requirements.txt`.

Clone the repository and move into its folder:

```bash
git clone https://github.com/SatelliteHub/total_variation_denoising.git
cd total_variation_denoising
```

After the final version has been tagged, select the submitted snapshot with `git checkout v1.0-submission`.

Create and activate a Conda environment, then install the dependencies:

```bash
conda create --name tv-denoising python=3.12.16 -y
conda activate tv-denoising
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Smoke run

Use a small development run to check that the environment works and both methods can run:

```bash
python run_experiments.py \
  --split development \
  --num-seeds 1 \
  --sigmas 0.10 \
  --size 96 \
  --iterations 20 \
  --timing-repeats 1 \
  --baseline-weight 0.20 \
  --alpha 1.0 \
  --output outputs/smoke.csv
```

This uses development seed 0 and one noise level. It runs both denoisers, prints MSE, PSNR and timing, and saves one paired row to `outputs/smoke.csv`. It should finish well under one minute. This is only an installation and code check; it is not used for the final results.

## Reproduce the full comparison

Run these commands in order from the repository folder.

### 1. Run the local checks

```bash
python -m unittest discover -s tests -v
```

The six checks cover small gradient and divergence examples, their negative-adjoint identity, preservation of a constant image, and output shape, finite values and input preservation for both methods. The checks should finish in a few seconds.

### 2. Select parameters using validation images

```bash
python run_experiments.py --tune-validation
```

The script compares fixed weights 0.05, 0.10 and 0.20 with adaptive scales 0.5, 1.0 and 1.5. It selects the values with the lowest mean MSE across the three noise levels. It saves `outputs/validation_tuning.csv`, a paired validation CSV and `outputs/selected_parameters.json`. The selected values for the reported run are baseline weight 0.20 and adaptive scale 1.0. This step should take about 10 seconds on the tested machine.

### 3. Run the independent test cases

```bash
python run_experiments.py --split test --config outputs/selected_parameters.json
```

This saves paired results to `outputs/test_alpha-1_weight-0.2.csv`. It reports MSE, where lower is better, and PSNR in decibels, where higher is better. It also reports paired gains and 95% bootstrap intervals. The test run should take about 10 seconds on the tested machine. Timing includes one warm-up and three measured runs per method and case; the CSV stores the median of the measured times. Adaptive timing includes noise estimation.

### 4. Save figures and the summary table

```bash
python plot_results.py
```

This reads the test CSV and saves:

- `outputs/test_overall_comparison.png`, with mean MSE and paired MSE gains with 95% bootstrap intervals
- `outputs/test_representative_example.png`, using test seed 2000 and noise standard deviation 0.10
- `outputs/test_overall_summary.csv`, with summary values and intervals

The plotting step should take a few seconds. To use another results CSV, pass `--results PATH`. Change the example with `--example-seed` and `--example-sigma`.

### 5. Run the textured stress case

```bash
python run_texture_stress.py
```

This uses 20 new seeds, 3000–3019, at noise standard deviation 0.10. It saves `outputs/texture_stress_results.csv` and `outputs/texture_stress_example.png`. The figure shows the full image and a zoom of the checkerboard region. The stress run should take about 5 seconds on the tested machine. Do not use these stress results to tune parameters.

The defaults use 96 by 96 images, 200 iterations, noise standard deviations 0.05, 0.10 and 0.20, and 20 paired seeds per level. Development seeds are 0–19, validation seeds are 1000–1019, and test seeds are 2000–2019. Test images are not used to select parameters. Gaussian noise is added without clipping.

## Limitations

- Images are synthetic rectangles and disks, not natural photographs
- The experiments assume independent additive Gaussian noise
- The noise estimate can be affected by edges and texture
- TV smoothing removes some real fine texture, as shown in the checkerboard stress case
- The results support conclusions about these generated images, not all image types

This project uses saved Matplotlib figures; it does not include a separate graphical interface.
