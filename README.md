# Total Variation Denoising

This repository contains an implementation of isotropic total variation (TV) denoising for greyscale images with Gaussian noise. The baseline follows Chambolle's fixed-point method and uses a fixed TV weight of $\lambda=0.20$. The modified method estimates the noise standard deviation, $\hat{\sigma}$, from the observed image and sets the weight to $\lambda=\max(\alpha\hat{\sigma},10^{-8})$. Validation data selected $\alpha=1.0$. Both methods use the same denoising algorithm, input images, step size and number of iterations; the TV weight is the part that changes.

The project is based on A. Chambolle, “An Algorithm for Total Variation Minimization and Applications,” *Journal of Mathematical Imaging and Vision*, 20, 89–97, 2004 ([DOI](https://doi.org/10.1023/B:JMIV.0000011325.36760.1e)). The discrete operators and synthetic image task follow the EEP55C36 handout, “Final-project mathematical guide: Image processing: total-variation denoising,” Trinity College Dublin, 2026. All images are generated by the project. No external image dataset or third-party denoising solver is used.

## Repository files

- `src/baseline.py` contains the fixed-weight Chambolle denoiser
- `src/modified.py` contains the noise-adaptive denoiser
- `src/data.py` creates synthetic images and estimates noise
- `src/metrics.py` calculates MSE and PSNR
- `run_experiments.py` selects parameters and runs paired comparisons
- `run_texture_stress.py` runs the checkerboard stress case
- `plot_results.py` creates the overall comparison and normal-image example
- `tests/test_denoising.py` contains six local checks
- `.vscode/launch.json` provides a VS Code launch option for the baseline demo
- `outputs/` stores selected parameters, result tables and figures
- `report/` stores the report source, PDF and PDF build script

The assignment shows `configs/smoke.json` and `configs/final.json` as an example layout. This project takes run settings from command-line options. The validation-selected values are saved in `outputs/selected_parameters.json` and are used for the full test run and the stress case. The commands below provide the other run settings.

## Tested environment and setup

The project was run on a MacBook Pro with an Apple M1 Pro chip and macOS 27.2.1. The environment used Python 3.12.16, NumPy 2.5.4 and Matplotlib 3.11.2. These package versions are pinned in `requirements.txt`.

Clone the repository and move into its folder:

```bash
git clone https://github.com/SatelliteHub/total_variation_denoising.git
cd total_variation_denoising
```

After the final version has been tagged, select the submitted snapshot with `git checkout v1.0-submission`.

Create and activate a Conda environment, then install the required packages:

```bash
conda create --name tv-denoising python=3.12.16 -y
conda activate tv-denoising
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Build the report PDF

The report source is `report/report.md`. It is written in Markdown, with LaTeX syntax used for equations. The build script uses Pandoc and XeLaTeX to create `report/report.pdf`. Both tools must be installed and available in the terminal.

Pandoc is a separate tool and is not installed by `requirements.txt`. Install it in the project environment with:

```bash
conda install --name tv-denoising --channel conda-forge pandoc
```

Check that both build tools are available:

```bash
pandoc --version
xelatex --version
```

After editing the Markdown file, run this command from the repository folder:

```bash
sh report/build_report.sh
```

The script creates or replaces `report/report.pdf`.

## Smoke run

Run a small development case to check that the environment and both denoisers work:

```bash
python run_experiments.py \
  --split development \
  --num-seeds 1 \
  --sigmas 0.10 \
  --size 96 \
  --iterations 20 \
  --timing-repeats 1 \
  --baseline-weight 0.20 \
  --alpha 1.0 \
  --output outputs/smoke.csv
```

This uses development seed 0 and one noise level. Both denoisers are run, MSE, PSNR and runtime are printed, and one paired result is saved to `outputs/smoke.csv`. The run should take well under one minute. It checks the installation and code; it is not used to produce the final results.

## Reproduce the full comparison

Run the following commands in order from the repository folder.

### 1. Run the local checks

```bash
python -m unittest discover -s tests -v
```

The six checks cover small gradient and divergence examples, their negative-adjoint identity, preservation of a constant image, and output shape, finite values and input preservation for both denoisers. They should finish in a few seconds.

### 2. Select parameters using validation images

```bash
python run_experiments.py --tune-validation
```

The script compares fixed weights of 0.05, 0.10 and 0.20 with adaptive scales of 0.5, 1.0 and 1.5. Values are selected by the lowest mean MSE across the three noise levels. The results are saved in `outputs/validation_tuning.csv`, a paired validation CSV and `outputs/selected_parameters.json`. For the reported run, the selected baseline weight is 0.20 and the selected adaptive scale is 1.0. The step should take about 10 seconds on the tested machine.

### 3. Run the independent test cases

```bash
python run_experiments.py --split test --config outputs/selected_parameters.json
```

Paired results are saved to `outputs/test_alpha-1_weight-0.2.csv`. MSE is reported, with lower values being better, along with PSNR in decibels, where higher values are better. Paired gains and 95% bootstrap intervals are also reported. The run should take about 10 seconds on the tested machine. Timing includes one warm-up and three measured runs per method and case. The CSV stores the median measured time. Adaptive timing includes noise estimation.

### 4. Save figures and the summary table

```bash
python plot_results.py
```

The script reads the test CSV and saves:

- `outputs/test_overall_comparison.png`, showing mean MSE and paired MSE gains with 95% bootstrap intervals
- `outputs/test_representative_example.png`, using test seed 2000 and noise standard deviation 0.10
- `outputs/test_overall_summary.csv`, containing summary values and intervals

Plotting should take a few seconds. A different results CSV can be selected with `--results PATH`. The example can be changed with `--example-seed` and `--example-sigma`.

### 5. Run the textured stress case

```bash
python run_texture_stress.py
```

The stress case uses 20 new seeds, 3000–3019, at noise standard deviation 0.10. Results are saved in `outputs/texture_stress_results.csv` and `outputs/texture_stress_example.png`. The figure shows the full image and a zoomed view of the checkerboard region. The run should take about 5 seconds on the tested machine. These results should not be used to tune parameters.

The defaults are 96 by 96 images, 200 iterations, noise standard deviations of 0.05, 0.10 and 0.20, and 20 paired seeds per level. Development seeds are 0–19, validation seeds are 1000–1019, and test seeds are 2000–2019. Test images are not used for parameter selection. Gaussian noise is added without clipping.

## Limitations

- The experiments use synthetic images containing rectangles and disks instead of natural photographs.
- Only independent additive Gaussian noise is considered.
- Edges and texture in the image may reduce the accuracy of the noise estimation.
- TV denoising can remove fine image details as well as noise, as observed in the checkerboard test.
- The results are limited to the synthetic images used in this project. Further testing is needed to evaluate performance on other types of images.

The results are visualised using figures generated and saved with Matplotlib. No separate graphical user interface (GUI) was developed.
